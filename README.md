# Learn Negotiation with Phoebe

Six 45-minute sessions on negotiation, by Phoebe Fu: positions and interests, walk-away points and
the deal zone, first offers and anchors, a bench of 4,000 real negotiations computed in the
browser, trading across issues, and saying no, closing and the next deal.

The running case, Kestrel Foods and Brightwell Packaging, is constructed for teaching. The bench
uses a seeded sample of the FAIR "Deal or No Deal?" dataset (Lewis, Yarats, Dauphin, Parikh and
Batra, 2017; github.com/facebookresearch/end-to-end-negotiator; CC BY-NC 4.0), shipped as derived
integer features only.

Static HTML: open `index.html`, or serve the folder with any static server.
